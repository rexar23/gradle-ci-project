# Gradle CI Project

## Сипаттамасы
Бұл жоба Java және Gradle көмегімен жасалған қарапайым оқу қосымшасы.
Қосымша екі санды қосу және көбейту амалдарын орындайды.

## Қолданылған технологиялар
- Java 17
- Gradle
- JUnit 5
- Git
- GitHub
- GitHub Actions

## Құрастыру
Жобаны құрастыру командасы:

./gradlew build

## Тестілеу
Тестілерді іске қосу командасы:

./gradlew test

## CI/CD
Жоба үшін GitHub Actions арқылы Build → Test CI/CD конвейері бапталған.
